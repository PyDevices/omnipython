# ttfio test font

`icons20.ttf` is ten icons from Google's Material Symbols Outlined (filled,
weight 400, 20 px optical size), cut down by omnipython-builds'
`modules/ttfio/tests/make_font.py`. Material Symbols is under the Apache
License 2.0, in `LICENSE` here; the source is
https://github.com/google/material-design-icons.
