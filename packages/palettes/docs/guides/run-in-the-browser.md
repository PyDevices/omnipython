# Run in the browser

palettes needs only Python, so it runs in a browser with PyScript or Pyodide.
These pages load it with `micropip` and draw with it:

- [palettes_demo](https://gallery.omnipython.org/pyscript/pyodide.html?modules=palettes_demo&deps=omnipython-palettes,omnipython-pygraphics): every palette family and color bar.
- [feathers](https://gallery.omnipython.org/pyscript/pyodide.html?modules=feathers&deps=omnipython-palettes,omnipython-pygraphics): generative curves colored from the wheel.
- [rotations](https://gallery.omnipython.org/pyscript/pyodide.html?modules=rotations&deps=omnipython-palettes,omnipython-pygraphics): palette cycling and sweeps.
- [scroll](https://gallery.omnipython.org/pyscript/pyodide.html?modules=scroll&deps=omnipython-palettes,omnipython-pygraphics): a scrolling gradient.

To use palettes in your own page, install it as in
[Install](../get-started/install.md#in-the-browser). The wheel's name is
`omnipython-palettes` and the module you import is `palettes`.
